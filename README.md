# Royal Indian Wedding — React + Vite

Converted from the supplied HTML/CSS/JS wedding invitation into a React + Vite project.

## Run

```bash
npm i
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
npm run preview
```

The design, typography, colors, responsive layout, scroll reveals, falling petals, countdown, gallery lightbox/navigation, venue link, and RSVP interaction are implemented in React.
